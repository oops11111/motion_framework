### 2. P0 IQR 门：应按帧相位分层

- 现行门结构上必然失败。假设 δ̂ = 常数 + 提交量化误差，量化误差在 [0, T) 内均匀分布（T = 16.67 ms），这一项单独的 IQR 就是 T/2 = 8.33 ms，已经超过 8 ms 门。实测 10.4 ms 约等于这 8.33 ms 再叠加约 3 ms 的随机抖动；范围 29.5–54.5 ms 宽约 25 ms，也是 1 帧量化加抖动的量级。
- 改法：
    1. 每次运行用合成器帧统计（`DCompositionGetFrameStatistics` 或 `DwmGetCompositionTimingInfo`）算出指令相位 φ = (tInt_m − lastFrameTime) mod T。
    2. 拟合锯齿模型 δ̂ = a + ((T − φ) mod T)·b，记残差 r = δ̂ − 拟合值。
    3. 门：b ∈ [0.8, 1.2]；按相位分 4 层，每层 IQR(r) ≤ 4 ms；全体 1.4826·MAD(r) ≤ 3 ms；残差 RMS 中位 ≤ 1 DIP。
- 主动控相位比事后分层更好。下发打断前先 `DCompositionWaitForCompositorClock` 对齐一帧，再精确等待到目标相位 φ*。这是程序化调度，不合成输入。

### 3. 打断后拟合怎么修，才能判 Δv

- workbuddy 提的“加自由起始相位”是退化的，不能用。弹簧方程是线性齐次的，参数固定时，起点前后平移只等于沿同一条轨迹换一组 (e0, v0)。现有的 (e0, v0) 两参数最小二乘已经吸收了这个自由度，再加起始相位不会降低残差。
- ⚠M 的规律指向时间戳抖动。打断后速度越高，⚠M 越多：
    - t060 速度约 1926 DIP/s，A 各臂 ⚠M 12–20/20。在这个速度下，1 ms 的时间戳误差就等于 1.9 DIP，比 1 DIP 门还大。
    - Am 各臂在 t156 的 seedV 约 900–1700，⚠M 都是 17–20/20。
    - t300 速度约 40，⚠M 是 0。
    - B 在 t060 的 seedV 只有 1044 和 155，⚠M 只有 2。
    
    所以现在的 ⚠M 主要说明“残差门没按速度加权”，不能直接说明“模型错了”。
    
- E3 修法（每次运行）：
    1. **帧范围**：用 k_c+1 … k_c+5 拟合。如果 k_c 帧和打断前模型的偏差 ≤ 1.5 DIP，把它归到打断前；否则直接剔除。
    2. **加权**：权重 wᵢ = 1/(σ_p² + vᵢ²σ_t²)，σ_p = 0.5 DIP；σ_t 取 P0 锯齿残差的稳健标准差，若取不到用 1.0 ms。⚠M 改判为 χ²/dof > 2。
    3. **M0**：按指令的 ω₀、ζ 和目标值，(e0, v0) 线性加权最小二乘。
    4. **M1**：M0 再加常数偏移 c，三参数线性，用来检查目标值或坐标偏移。
    5. **M2（只作诊断）**：在网格 s = ω₀ 缩放 ∈ [0.8, 1.25]、ζ ∈ [0.6, 1.0] 上搜索。如果 M2 明显好于 M0，就是实际参数和指令不一致，记 PARAM-MISMATCH。
    6. **Δv 取值**：只用 M0 通过的运行；M1 通过且 |c| ≤ 1 DIP 的也可用。t_s 定义为 tInt_m 之后第一个合成器帧时刻，Δv = v_post(t_s) − v_pre(t_s)。
    7. **格级可判**：本格 ⚠M ≤ 2/20 才判 Δv；否则这一格只判 J。
