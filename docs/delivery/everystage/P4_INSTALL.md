# EveryStage 0.9.2：内部安装、升级与卸载

本目录交付 Windows10 2004（build19041）及以上/Windows11 x64 的 NSIS 安装器；不是 DEV-ONLY ZIP，也不是公开发布。安装器和组件包是 post45011904252 已测试的原字节。安装器实际 **NotSigned（未代码签名）**；外部验收 JSON 是来源/验收记录，不是代码签名或可信发布者证书。

先阅读 [校验说明](P4_VERIFY.md)。最终正式内部交付以同目录 ROOT_ACCEPTANCE.json 与完整校验通过为准。此次整理没有在用户机运行安装器或启动现有 EveryStage，也没有读取或修改既有 ProgramData/ProgramFiles 配置。

## 安装

1. 对照 SHA256SUMS/manifest.json，核验 `EveryStage-Setup-0.9.2-win-x64.exe`。只从可信内部交付取得并自行决定运行；未签名警示不应被误述为已签名。
2. 运行安装器并由操作者确认管理员权限。默认安装终端机 Terminal；交互页可选投屏机 Caster 或两者。按现有安装逻辑写 Program Files、公共快捷方式、HKLM 自动启动与局域网 UDP47990–47992 防火墙规则，并为共享 ProgramData 数据设置权限。
3. 安装器自带 .NET 运行时。Word/PPT 功能依赖单独可用的 WPS/Office，其安装和授权不在本交付内；真实投屏、媒体、Office、物理显示器及性能未获本次认证。组件本机 DLL 采用静态 CRT 构建，不据此断言所有第三方嵌套本机依赖均无需外部条件。

仅供受控内部部署：`EveryStage-Setup-0.9.2-win-x64.exe /S /COMPONENTS=Terminal`，有限值为 Terminal/Caster/Both。省略参数保留原有默认/旧组件选择；非法值在安装变更前退出2。静默参数不是用户机自动执行授权。

## 从 0.9.1 升级

升级前从通知区域 EveryStage 图标菜单选择 **退出**，确认进程结束。关闭主窗口的 X/WM_CLOSE 只是隐藏，不能代替退出。然后运行0.9.2安装器；正常升级替换已选组件程序文件，保留 ProgramData 数据。CI 已验证官方指定0.9.1原安装包→本次0.9.2、旧程序文件清理和自建数据逐字节保留；不代表所有历史版本或任意用户数据迁移均已测试。建议操作者按自己的数据策略备份。

`baseline/baseline.zip` 是原0.9.1已测升级输入的离线保存，不是推荐安装版本，更不是降级配置兼容性证明。不要把它当作降级恢复流程运行。

## 卸载

同样先通过真实托盘菜单退出。在“已安装的应用”或安装目录 Uninstall.exe 正常卸载。默认保留 `%ProgramData%/EveryStage`；显式选择删除配置/配对（静默 `/S /DELETEDATA=1`）会删除应用数据但保留 logs。媒体源文件不等于应用配置；此次测试使用的是全新 runner 自建数据，未接触用户文件。

主代理核验了 post 源提交、27输入文件、9包成员、实际加载的托管/本机组件、同 PID/starttime 的正常托盘退出0、9次安装/卸载调用0、三组件组合与清理，以及六张普通安装应用截图。post 的 opening 采样仍是关闭态，随后最终展开/resize展开/Esc关闭清楚；不声称精确时长或该帧证明在途反向。P2 的实际控件连续性测试是独立证据。
