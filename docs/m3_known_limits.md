# M3 已知限制（框架文档草稿）

> 起草：Claude，2026-11-01（pidan S4）。随诊断结果更新；当前内容基于 M3-XAML-LOST、M3-XAML-REBUILD 的真机数据。

## L-XAML-1 显卡驱动重启后，WinUI 3 宿主的 XAML 界面可能不再绘制
- **现象**：显卡驱动重启（驱动更新、驱动崩溃后系统重启驱动、`pnputil /restart-device`）之后，应用里所有需要 XAML 自己光栅化的内容——文字、圆角元素、按钮、开关、标题栏图标和标题——全部消失且不再重画；纯色矩形仍然在更新，XAML 仍在出帧。重启前已打开的其他窗口、重启后新建的窗口同样画不出来（整个进程受影响）。改窗口大小、最小化再还原、重设页面内容都不能恢复。**重新启动应用后恢复正常。**
- **框架自己的 Rive 内容不受影响**：M3-RIVE-LOST-RECOVER 已验证 Rive 表面能在 2.1–2.3 s 内自动恢复。
- **已观察到的环境**：DESKTOP-IJI1KJG，Windows 11 build 26300（预览通道），AMD Radeon RX 7800 XT（驱动 32.0.12033.1030），WinAppSDK 2.5.1；unpackaged + self-contained 与打包部署都会出现。
- **未出现的环境**：DESKTOP-K93N3P8，Windows 10 19045，NVIDIA GTX 970（驱动 32.0.15.8278），打包部署——主窗口在驱动重启后完整。**但该会话未能证明应用设备确实丢失**，正在由 M3-XAML-K93 确认。
- **对宿主应用的建议（暂定）**：
  1. 框架在 Rive 渲染线程检测到设备丢失时，通知宿主（事件或回调）；
  2. 宿主不要依赖“重建窗口”来恢复界面（已证实无效）；
  3. 宿主应提示用户重新启动应用，或在保存状态后自行重启。
- **对外报告**：待 M3-XAML-K93 结果。若问题只出现在预览版 Windows 或 AMD 驱动上，向 Windows 反馈中心或 AMD 报告；若普遍存在，考虑向 microsoft-ui-xaml 报告（由 pidan 决定）。
