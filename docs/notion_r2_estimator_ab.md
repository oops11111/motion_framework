## A

**结论**

- **不加加速度项。** remap 后弹簧很快，帧间状态变化大。2 阶外推要对量化噪声做二次差分，噪声会按 1/Δt² 放大；ω·Δt 不小时，泰勒截断误差也不会随阶数收敛，所以只会更不稳。
- **也不把同时刻 base 轨迹直接当零假设。** rev、fwd、dbl 打断后目标变了，打断后的那一段 base 没有对应轨迹，不能拿来比。
- **改用模型拟合估计器 E2。** 弹簧参数（Period、ζ、目标）都是已知的指令值，只需从帧数据里拟合状态，不做差分：
    - 打断前：用整段打断前的帧拟合屏幕延迟 δ，得到 x_pre(τ)、v_pre(τ) 的解析式。
    - 打断后：用打断后 2–6 帧做 2 参数线性最小二乘，拟合 (e₀, v₀)。
    - 在切换窗口内找两条轨迹最接近的时刻 t_s，在 t_s 比较 J 和 Δv。
    - base 用同一流程算零假设：目标不变，J_null 和 Δv_null 理论上只剩量化噪声。
    - base 中位轨迹只作交叉核对，不进判据。
- **Δv 先过"可判"门再判。** 先用 base 的 Δv_null 检查这一格能不能判；不能判的格只看 J，标 J-only，不能算 PASS。
- **负 lead 不用 −35/−39/−42。** 三个点只差 3–7 ms，远小于 1 帧（16.7 ms），而且根本没覆盖到约 70 ms 一带。改为先只跑 base 标定 Δt̂，再用 {0, 39, Δt̂−15, Δt̂, Δt̂+15} 扫描。标定失败时 Δt̂ 默认取 70。Bs 因 J 最差，本轮去掉。

**#43 编号算法**（只用程序化动画，不合成输入，不动鼠标）

1. **记号**
    - ω₀ = 2π/Period，Period 取探针实际下发的 r/(2π)；r=0.32，ζ=0.78；ω_d = ω₀·√(1−ζ²)。
    - 设 s = τ − τ_ref，e = x − T（T 为目标）。基函数：
        - φ₁(s) = e^(−ζω₀s)·[cos(ω_d s) + (ζω₀/ω_d)·sin(ω_d s)]
        - φ₂(s) = e^(−ζω₀s)·sin(ω_d s)/ω_d
    - 位置 e(s) = e₀φ₁ + v₀φ₂；速度 v(s) 取它的解析导数。
    - 帧时间 t_k 用 WGC 的 SystemRelativeTime；模型时钟 τ_k = t_k − δ。
2. **P0 标定（只跑 base，40 次）**
    - 每次在 δ∈[0,150] ms 上按 0.5 ms 网格搜索，最小化全部帧与 x_model(t_k−δ) 的 SSE（x_model 由已知起点、目标、指令起始时刻确定）。
    - 得到每次的 δ̂_run。Δt̂ = 中位数，并给 bootstrap 95% CI。
    - 失败条件：δ̂_run 的 IQR > 8 ms，或拟合残差 RMS 中位 > 1 DIP。此时报 MODEL-MISMATCH，停止并回报，不进入 P1。
3. **P1 臂设置**
    - **A0**：种子 = spring.h(r) 在 tInt_c 的 (x, v)。
    - **Am_X**：种子 = spring.h(r) 在 tInt_c − X 的 (x, v)，X∈{39, Δt̂−15, Δt̂, Δt̂+15}，四舍五入到 1 ms。不再做 τ−L 换算，L 只事后记录。
    - **B**：同 #35/#42 的 B。
    - 共 6 臂 × 7 格 + 1 base = 每轮 43 次；20 轮共 860 次。每轮内随机打乱顺序。
4. **打断前模型（每次运行）**
    - 用 k_c 之前的全部帧按第 1 步拟合本次的 δ_run，得到 x_pre(τ)、v_pre(τ)。
    - dbl 格的第二次打断前段同理。
5. **打断后拟合**
    - 帧 k_c … k_end，k_end = min(k_c+5, |e|<1 DIP 的前一帧, 下一事件前一帧)。
    - 少于 2 帧标 NA；NA 次数 > 3/20 的格记为不可判。
    - T 和 Period 用该臂实际下发值；τ_ref = τ_{k_c}。
    - 对 (e₀, v₀) 做线性最小二乘，得到 x_post(τ)、v_post(τ)。
    - 记残差 RMS_post；RMS_post > 1 DIP 时该次标 ⚠M。
6. **切换点与指标**
    - 窗口 W = [τ_{k_c−1}, τ_{k_c}]，按 1 ms 网格。
    - t_s = argmin over W of |x_post − x_pre|。
    - J = |x_post − x_pre|(t_s)；Δv = |v_post − v_pre|(t_s)；v_ref = v_pre(t_s)。
    - 同时记录 t_s − τ_{k_c−1}，作为 L 的替代量。
7. **零假设**
    - 本轮 base（n=20）用该臂的 k_c 和窗口，按第 3–5 步计算，打断后目标仍取 T_old。
    - N_h_cell = J_null 第 19 小，N_h_eff = max(N_h_cell, 1.0)。
    - Nv_h_cell = Δv_null 第 19 小。
    - 交叉核对：用 base 中位轨迹（按 δ̂_run 对齐后插值）代替 x_pre 再算一次 J。若与第 5 步的中位差 > 1 DIP，该格标 ⚠E。
8. **门**
    - J 门：N_h_cell ≤ 4（R-2′ 原规则不变）。
    - Δv 阈 = max(20, 5%·|v_ref|)。
    - Δv 可判：Nv_h_cell ≤ 该格阈的中位，否则该格为 J-only。
    - 会话作废：base 有 ≥3/7 格未过 J 门，或 P0 失败。
9. **判定**
    - 单次通过：J ≤ N_h_eff，且（可判格才看）Δv ≤ 阈。
    - 格 PASS：单次通过 ≥ 17/20，且 J 中位 95% bootstrap CI 上界 ≤ N_h_eff，且 Δv 中位 ≤ 阈中位。J-only 格最高只能记 J-PASS。
    - 臂通过：可判格全部 PASS，且可判格 ≥ 5/7。
10. **lead 反解**
    - 在 t060/t156 格，对 J 中位和 Δv 中位分别做关于 X∈{0, 39, …} 的二次拟合，求极小点 L*_J、L*_v。
    - 与 Δt̂ 相差 ≤ 8 ms 时记为一致，取三者中位作为 Δt_eff。
    - 不一致时如实回报，不做裁决。
11. **选主**
    - 有通过的臂：选 J 全格中位最小者。
    - 无通过的臂：维持 hybrid B 为 M1b，回报 L* 和各门状态。
12. **输出**
    - 每臂一张格表，列：n、k_c、N_h_cell、Nv_h_cell、可判、J 中位[CI 上界]、Δv 中位（阈中位）、通过数、t_s−τ_{k_c−1} 中位、v_ref 中位、seedV 中位、⚠M/⚠E、结论。
    - 另附 P0 的 Δt̂[CI]、L* 表和 Δv_null 表。
