## A

**裁决**

1. **R-2 门槛改为“底噪相对门”。** harness 底噪 N_h=3.11 DIP，已经高于原严格门 0.5 DIP，所以“J_vis ≤ 0.5 DIP”在当前 harness 上测不出来，不能作验收门。0.5 DIP 降为 M2 目标值，等底噪 < 0.5 DIP 后再恢复。新门槛 R-2′：
    - **①′ 单次 J_vis 门：** `J_vis(run) ≤ G_J(run) = d_frame(run) + N_h`
        - d_frame：打断前 WGC 末两帧的位移，`|x2 − x1|`（DIP），逐次计算。
        - N_h：同一会话中 ≥20 次不打断基线测出的 harness 底噪，沿用 #35 得出 3.11 的同一算法，每次会话重测并写入结果头。
        - 会话有效性：N_h > 4 DIP，或超过上一有效会话的 2 倍，则整个会话作废。
        - 逐格通过率 ≥95%（n=20 时 ≥19/20）。dbl 格在冻结验证时要求 n≥60 且 0 失败；n=20 全过时 Clopper-Pearson 下界只有约 83%，证不了 95%。
    - **②′ 相对 A 的改善：** 7 格合并后，`median(J_X)/median(J_A)` 的 95% bootstrap CI 上界 ≤ 0.25；逐格只要求点估计 ≤ 0.25。原来逐格“CI 不重叠”的判据作废：A 在 t156rev / t300rev 有少量落在近 0 区的样本，分布是双峰，这一条测的是 A 的双峰，不是 X 的优劣。
    - **③′ Δv 门：** 逐格 `median|dvel|_X ≤ median|dvel|_A`，且合并后 `median|dvel|_X ≤ 0.25 × median|dvel|_A`。绝对门 `max(20, 5%|v|)` 降为 M2 目标。
    - **对 #35 的判定：** B 的①′按 #35 已列的“帧位移 + 3.11”宽阈为 7 格全部 20/20；③′逐格全过，合并 58 ≤ 0.25×359 ≈ 89.75，通过。②′我没有算，需要用 #35 原始日志重算（不用重跑）：合并点估计是 2.02/170.17 ≈ 0.012，预计能过，但正式数字以重算为准。dbl 格 n=20 全过还不够，要补到 n≥60。
2. **hybrid B（WGC 末两帧速度）可以作为 M1b 缓解上线，flag 默认开。** 理由：A 就是当前缺陷，可见跳变约 207 DIP；B 在 7 格里 J_vis 和 Δv 全部优于 A，J 比值 0.01–0.02。上线条件：
    - C1：IV=null 取动画中当前值（#34 P1 已在 DESKTOP-K93N3P8 上证实）。
    - C2：B 的速度只取 WGC 末两帧 `(x2−x1)/(t2−t1)`（DIP、到达 QPC）。禁止用 spring.h 影子速度：#37 测得影子速度约为屏幕速度的 2.6 倍。
    - C3：速度可信性守卫。以下任一情况视为速度不可信：WGC 不可用、末帧距打断时刻超过 2 个帧周期、`dt12 ∉ [0.5, 2] × 帧周期`。不可信时降级为 IV=null + InitialVelocity=0，**不能回退到 A**。降级要计数并写日志。
    - C4：保留 kill-switch，关掉 hybrid B 等于走 C3 的降级路径，不是回到 A。
    - C5（冻结前置）：#35 原始数据重算②′通过；在第二台机器（换刷新率，例如 120/144 Hz）上补测 t060rev、t156dbl 两格（t156dbl n≥60，t060rev n≥20），按 R-2′ 通过。C5 不过时，flag 默认改为关，R-2 继续作为限制项开着；但 B 仍可以 opt-in。

5. **对 M1b 冻结和 M2 的影响：**

- **打断动画后的速度残差（R-2）**
  打断进行中的动画（retarget）时，位置续接可见残差约 2–3 DIP，在一帧位移加测量底噪的范围内，肉眼一般看不出。
  但打断后仍有小幅速度不连续，中位约 30–90 DIP/s，反向打断较明显（如约 60 ms 时反向打断，中位约 87）。
  成因：打断速度取自屏幕捕获（WGC）的末两帧，受帧时间抖动影响。
  捕获不可用或帧过旧时，自动降级为“取当前值、初速度 0”，此时会出现可见的减速再加速。
  同一 tick 内连续两次 retarget 已覆盖测试，但目前只在单台 60 Hz 机器上验证过；高刷新率设备的表现待验证。
  需要完全平滑衔接时，请使用 opt-in 的 interruptible 动画。
  如遇异常，可关闭 flag `interrupt.hybridB`（关闭后走降级路径，不会回到旧的影子 seed）。
