关于 ③ 里的 k_c：「k_c≤1.5 归前」的计数和 PASS 高度重合。

所以必须离线重算两种口径：强制不归前、强制归前，并列出各臂各格的 J 和 Δv。如果某格只在一种口径下通过，标「k_c 敏感」，不能算稳健通过。

**二、t156 Δv 不可判怎么办**

1. **#45 的结论不受影响。**
    - 非 t156 格最多 4 个，③ 要求可判 ≥5/7，所以现行规则下任何臂都不可能满足 ③。
    - 即使 t156 变成可判，按现有中位：A+8 t156 三格 Δv 为 54 / 82 / 53，都大于阈 26；A0 t156rev 35、t156dbl 34.5 也大于 26。两臂照样过不了 ③。
2. **判定改成不对称（从 #47 起执行，不追溯）。**
    - Nv_h 只用来证明「通过」。
    - 当 Δv 的 CI 下界大于「阈 + Nv_h」（= 45.7）时，即使不满足可判条件，也直接判「FAIL-确定」。
    - 按这条，B t156 三格（约 1320）明确是真实的速度不连续。
3. **先用现有数据离线修估计器，不新跑。** t156 的 base Δv_null 约 19.3，是 t300 的 10 倍。初步判断：t156 处于强减速段，局部线性的速度加权 LS 有模型偏差。
    - 首选 E3r：用已知的 ω0、ζ 解析轨迹减掉 base 轨迹，在残差上做前后两段斜率差。
    - 备选 E3q：局部二次拟合。
    - 通过门槛：用 #45 base 重算，t156 三格 Nv_h ≤ 13（阈的一半），且 t060 / t300 的 Nv_h 增幅 ≤20%。
4. **如果 E3r 和 E3q 都过不了门**，t156 的 Δv 定为「结构性不可判」。#47 起 ③ 改为：
    - 非结构性不可判的格全部可判、且全部达标；
    - t156 三格都没有 FAIL-确定；
    - t156 三格 J 通过。
    
    这条修订必须在 #47 开跑前登记。
    

**三、A+8 是否值得追**

**不作为候选臂追，只做零新跑的诊断，过不了就关闭。**

- **偏置巧合的证据：**
    - A+8 在 rev 方向接近零误差（0.13 / 0.05），fwd 方向偏大（3.21 / 3.66）。
    - A0 本身就有方向差：t060 rev 8.82、fwd 4.52。说明不对称来自系统或探针，不是 8 ms 补偿学到的东西。
    - A+8 的 J 中位 0.18 掩盖了 3 个 J>1 的格。
    - 它的通过格和 k_c 归前完全重合。
- **诊断 1：** 做上面的 k_c 双口径重算。A+8 的通过格一旦翻转，立即关闭。
- **诊断 2：** 输出有符号 J，用 A0 和 A+8 两个点按格、按方向插值出最优前置量 L*（L* = 8·J0s / (J0s − J8s)）。
