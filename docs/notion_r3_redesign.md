# R-3 方案重设计（修订稿）

**记法：** 本稿统一写作 `base + d0 + d1`。

- `base`：打断前的静止基准。
- `d0`：仍在运行的旧弹簧。
- `d1`：重定向时叠加的步进项。

旧稿主记法是 `b + d1`（b 相当于 base 与 d0 合在一起），本稿不再用作主记法。

**数字标注：**

- 标 **derived** 的是闭式推导值，参数为 ω0≈19.635、ζ=0.78，与 Period 和 ζ 配置一致。
- 标 **proposed** 的门槛只是提议。
- 实测值只引用 #48 和 #49 已有的结果。

**硬约束：**

- 只用程序化 Composition。
- 禁止合成输入。
- 不改 `composition.h`，当前仍为 a55d4952…e418。
- 不编造未测数字。

**历史结论不变**

### A.2 S1 原理（保留）

在重定向时刻，用估计延迟 ε̂ 给 d1 加种子：初始位置 IV=s(ε̂)，初始速度 IVel=s′(ε̂)。这样 d1 从"已经走了 ε̂"的状态开始，用来抵消响应延迟 ε。

**时间平移恒等式成立。** 在同一 Period 和 ζ 下，种子 (s(ε̂), s′(ε̂)) 产生的后续轨迹与 s(t+ε̂) 完全一致。闭式核对的最大偏差约 3.3e-16·Δ（derived），只是数值噪声。

### A.3 敏感度（改正）

旧稿把残差对 ε̂ 误差的敏感度当作二阶，这是错的。

**残差是一阶的。** 设 e = ε̂ − ε（e>0 为超前，e<0 为滞后），则位置残差 ≈ s′(t)·e。

- 系数上限是步进的峰值速度，约 **8.45·Δ /s**（derived，出现在 t≈55 ms 附近）。
- 旧稿用的二阶项 ½ω²Δe² 偏小。e=±5 ms 时低估约 **9×**（derived）。

**S1 只在 ε 可预测时才明显有益。**

- 取常量 ε̂=21.8 ms，而 #49 两档实际 ε≈11–30 ms。
- 期望残差约 **0.07–0.09·Δ**。
- 这相当于把滞后误差降低约 2×，不是消除。
- 这些是由实测 ε 分布代入闭式得到的期望值，**不是测量值**。

### A.4 落地跳变（写清代价）

S1 没有消除延迟，而是把响应延迟换成两项有意的代价：落地位置跳变（hop），以及速度折点（kink）。

| ε̂ | 落地位置 s(ε̂) | 速度阶跃 s′(ε̂) | 备注 |
| --- | --- | --- | --- |
| 21.8 ms | 0.073·Δ | 5.95·Δ DIP/s | derived；二次近似给出 0.092·Δ，偏高 |
| 16.7 ms（一帧） | 0.045·Δ | 4.95·Δ DIP/s | derived |

**缓解：** 可以把 advance 封顶为一帧（ε̂ ≤ 16.7 ms），以限制 hop 幅度。代价是 ε 较大的那一档会留下残余滞后。

### A.5 门控现状的问题

旧稿用「J/Δv ≤ 2× 同批 Sup」作 S1 出货门，这条**作废**，原因有两个：

1. 对照不公平。Sup 从静止启动，S1 则有意落地在种子状态，两者的 J 和 Δv 天然不可比。
2. Δv 在算术上随 Δ 增大。大 Δ 的格子容易假 FAIL。

## C. 修订后的 #50 派单

**裁决：conditional GO。** C.1 的 P0-fit 和 C.2 的 ε 定义检查全部通过后，才可以开跑 C.4 主矩阵。

### C.1 扩展的 P0-fit（主矩阵的闸门）

1. **种子平移检验**
    - 取若干 τ0，设 IV=s(τ0)、IVel=s′(τ0)。
    - 用 WGC 捕获轨迹，拟合到静止启动曲线平移 τ0 后的结果。
    - 要求拟合残差在 #47 逐格的 N_h 以内。
2. **Δ 线性**
    - 检验不同幅度、正负号的 Δ 下，轨迹是否按 Δ 线性缩放。
3. **叠加检验**
    - d1 在运行中的 d0 之上叠加，并由 Expression 求和得到 base + d0 + d1。
    - 屏幕轨迹应等于各项闭式之和。
4. **门槛口径**
    - 一律使用 #47 的逐格 N_h，不引入新常量。
5. **停止条件**
    - 任一项残差超出 N_h，就停止主矩阵，转入 C.6 的分流。

### C.2 ε 定义检查

- 打断前的弹簧（d0）必须与 d1 走同一条 PS/Expression 路径。
- 否则测到的 ε 里混有路径差，这样标定出的 ε̂ 无效。
- 不满足时先统一路径，再测 ε。

### C.3 门控（重写）

| 类别 | 内容 | 性质 |
| --- | --- | --- |
| **出货门** | `J_vis ≤ d_frame + N_h_eff`（#47 口径） | proposed |
| **S1 主指标** | 相对理想重定向轨迹的有符号残差：落地帧以及之后若干帧的位置和速度 | 报告项 |
| **滞后分布** | 有符号 e 的 median / P90，按 φ 分档；**超前（e>0）和滞后（e<0）分开报告** | 报告项 |
| **Sup 时代对照** | 「ε 中位 ≤ 16.7 ms」 | 对照，不作 S1 唯一硬门 |
| **作废** | 「J/Δv ≤ 2× 同批 Sup」 | 禁止用作 S1 出货门 |

超前（e>0）要单独看：目标就在当前位置前方不远时，超前可能放大过冲，需要独立检查。

**ε̂ 扫描**

| --- | --- |
| 0 | 等于 Sup，作对照 |
| 16.7 ms | 一帧，也就是 advance 封顶值 |

**多 cell**

- 在 t060 之外，至少再加不同速度的格子和反号 Δ 的格子。
- 只有 t060 一格不足以下结论。

**φ 分档**

- 每个桶的样本量要足够。

**实验纪律**

- 各臂交错并随机排序。
- 每格都要有不打断的 baseline。

### C.5 报告格式

- 逐 trial 给原始行，字段为 `φ, ε, e, J, Δv, N_h_eff`。
- 汇总给有符号残差（位置和速度，落地帧及之后若干帧）的 median / P90，按 φ 分档，超前和滞后分列。
- 闭式值标 derived，门槛标 proposed，实测值注明来源批次。

### C.6 成功 / 失败 / 分流

**成功：** 以下全部满足，才可以提请 Claude 复核。成功不等于宣布采用，R-3 仍保持 OPEN，直到复核结论出来。

- P0-fit 全部通过。
- ε 定义检查通过。
- 至少一个 ε̂ 在所有 cell 上满足 `J_vis ≤ d_frame + N_h_eff`。
- 有符号残差相对 Sup 有降低，且超前一侧没有出现新的过冲问题。

**失败：**

- P0-fit 的种子平移或叠加残差超出 N_h：说明平台不支持 S1 的前提，S1 停止。
- S2 之后 ε 仍然不可预测：按 φ 分档后 hold-out 的 e 分布太宽，残差无法明显低于 Sup。此时 S1 的收益不成立。

**分流：**

- hop 和 kink 不可接受、但滞后有收益：试 advance 封顶一帧（16.7 ms）。
- 只有部分 φ 档有收益：评估产品侧 φ 估计（DwmFlush）的 S1-φ 变体。
- 多次 retarget 的折叠失败：把 live terms 上限列为出货限制，不扩大适用范围。
- 以上都无效：S1 降级，回到 S4（E2）或 S5 底线讨论。S5 本身不关闭 R-3。
