## A1c（改：宽 ε 界 + 撞界 INVALID + 双模显式判据）
- 协议：d0:0→240 运行中叠加 d1:0→−120于 tInt≈60 ms；≥5 reps（#52 harness 可加到 12 以利 P1）。
- ε 搜索界（宽）：ε ∈ [−40.0, +40.0] ms，步长 0.5 ms。
- **撞界规则**：若最优 ε 落在界端点（|ε−(−40)|<1e-6 或 |ε−(+40)|<1e-6），该 trial=**INVALID**；会话若存在任一 INVALID trial，则 A1c=**INVALID**（不得记 PASS/FAIL）。
- 有效 trial：未撞界者。对其记录 ε_fit 与 RMS。
- **双模显式判据**（写死）：
  1. 模态中心 μ+ = +6.5 ms，μ− = −10.0 ms；归属半径 R = 4.0 ms。
  2. 将每个有效 ε_fit 归入 nearest({μ+, μ−}) 若距离 ≤ R，否则归入 OTHER。
  3. A1c=PASS 当且仅当同时满足：
     (a) 无 INVALID trial；有效 trial 数 ≥5；
     (b) OTHER 计数 = 0（所有有效 ε 落在两模之一）；
     (c) 全体有效 trial 的 RMS 中位 ≤ N_h=0.41；
     (d) 若两模均非空：|median(ε|μ+) − median(ε|μ−)| ∈ [14.0, 19.0] ms（≈1 帧）；若仅单模非空：亦允许（单模稳定）。
  4. 不满足 (a)–(d) 且无 INVALID → A1c=FAIL。
- 禁止用「全体 ε 中位」掩盖双模；必须按上列分模报告 n+/n−/OTHER。
